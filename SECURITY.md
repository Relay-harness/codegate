# Security policy

CodeGate v0.1 is an experimental local quality gate, not a sandbox or a security boundary. Local hooks can be bypassed. Review the [trust model](DESIGN.md) before using it for shipping decisions.

## Reporting a vulnerability

Please use [GitHub private vulnerability reporting](https://github.com/Relay-harness/codegate/security/advisories/new) to report a security issue. Do not open a public issue with exploit details or credentials. Include a minimal reproduction, affected version or commit, impact, and a safe way to reach you. If private reporting is unavailable, contact the repository owners privately before disclosing details; do not post them publicly.

Maintainers will assess reports and coordinate fixes and disclosure when possible. This volunteer project does not promise a response time or security fixes for every report.

## Supported versions

Only the latest code on the default branch is currently maintained. There is no separately supported release line.
